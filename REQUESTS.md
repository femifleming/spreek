- 2026-11-15 — "also check that the dutch and vocal synthesis moules work well and push those as a bundle to my github, homebrew. and make sure they all have pdf manuals and work on mac windoes and linux." → both built with JUCE 9.0.5, tests + auval + a DAW-style host check; one repo femifleming/spreek with mac (universal) / Windows / Linux CI releases, casks `spreekbuis` and `spraakmaker`; the macOS-only parts (AVSpeech renderer, Application Support paths) behind platform guards, a cross-platform renderer (SAPI / piper / espeak-ng) and the built-in Klatt voice as the fallback so Spreekbuis is never silent; the moddict wordmark and the Phonemer name removed from Spraakmaker (an homage, see README); PDF manuals regenerated and shipped in every zip
- 2026-11-15 — the Dutch voice should be "very high quality, not old tts dutch" → the renderer picks the best installed voice (Premium > Enhanced > compact); on this Mac only the compact Xander / Ellen are installed, so the renderer gained a Piper engine (neural VITS voices nl_NL-pim-medium / nl_BE-nathalie-medium, en_US-lessac-medium for the glosses; `render.py --setup-piper` installs it on any OS, the Tongval venv is reused here), preferred over Apple / SAPI / espeak; then a Voxtral engine above it (Voxtral-4B-TTS via mlx-audio, Apple Silicon only, nl_male / nl_female; `--setup-voxtral`; the Tongval venv and weights are reused); the local banks were re-rendered with Piper and then with Voxtral (66 + 43 min). Found on the way: Piper's English clips were ~8 dB hotter than Apple's and Voxtral's Dutch ~3 dB, which let the whispered translations drown the vowel pad's shaping of the word cloud; the renderer now levels every clip to −16 dBFS speech loudness (`render.py --normalize` re-levels a bank) and SBTest's klinker check measures the shaping itself (whisper off, level-independent metric). Apple's Xander (Enhanced) / Claire (Premium) remain the macOS fallback once downloaded in System Settings
